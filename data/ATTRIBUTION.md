# Data attribution

V8.0.0 sources:
- HSK word lists: https://github.com/plaktos/hsk_csv
- English-Vietnamese dictionary entries and paired examples: https://github.com/chuongmep/vi-en-dictionary
- Runtime TTS audio URLs: https://dict.minhqnd.com/

The 500-word package is stored as additive expansion500 records and cross-linked into sentences, questions, trilingual, communication and grammar practice. Existing app data and user progress are preserved.
